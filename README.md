# Assignment 1 — Interactive Sketch

Make one interactive sketch in p5.js and put it live on your website.

**Due:** Week 3, October 7, before class.

## What to make

A sketch that reacts when someone uses the mouse and the keyboard. It can be a toy, a creature, a game, a machine that does nothing useful. Anything.

Make it fun and weird. The stranger and more playful it is, the better. **Bonus points** for weird.

It's fine if it's simple. I care more that you understand your code than that it's big.

## It must use

- [ ] **Several shapes** — at least three kinds, like `circle()`, `rect()`, `triangle()`, `line()`, `arc()`.
- [ ] **The mouse** — `mouseX`, `mouseY`, `mouseIsPressed`, or `mousePressed()`.
- [ ] **The keyboard** — `keyIsPressed`, `key`, or `keyPressed()`.
- [ ] **Conditionals** — `if` / `else`. Something changes when something is true.
- [ ] **Randomness** — `random()`. Something is different each time.
- [ ] **An array** — a list of things, like colors, positions, or words, that your sketch uses.
- [ ] **A function you wrote** — at least one of your own, besides `setup()` and `draw()`.

## In class

On October 7, I will ask some of you to show your sketch and walk us through the code. Be ready to answer:

- Where did you use each thing on the list?
- What happens when I click? When I press a key?
- What was hard? What broke?
- What surprised you?

If something doesn't work, that's fine. Bring it and we'll talk about it. That's how we learn.

## Some tips

- Plan ahead. Write what you want to do. In simple steps.
- Sketch. what you want to happen.
- Look at youtube videos. Tutorials. Etc.
- think of something weird and fun and write it down.
- It is also a viable approach to start coding and see if something weird pops up.
